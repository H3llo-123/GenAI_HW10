# 財務報表概論 (Financial Statements Overview)

## 一句話定義
財務報表是會計溝通的核心工具，透過一套標準化、相互勾稽的制式報表，完整呈現企業的經營績效、盈餘分派與財務狀況。

## 詳細說明
會計系統定期或非定期產出四大制式財務報表：

1. **損益表 (Income Statement)**：反映企業在「特定期間」的營運成果，計算收入減去費用後的淨利或淨損（流量資訊）。
2. **保留盈餘表 (Retained Earnings Statement)**：反映企業在「特定期間」保留盈餘的增減變化，串聯當期獲利與股利分派（流量變動資訊）。
3. **資產負債表 / 財務狀況表 (Balance Sheet / Statement of Financial Position)**：反映企業在「特定時點」的資產、負債與權益狀況（存量資訊）。
4. **現金流量表 (Statement of Cash Flows)**：說明特定期間現金如何由期初餘額轉變至期末餘額，協助報表使用者了解企業產生現金之能力與未來現金需求（依規範一句話帶過）。

### 嚴格的編製順序與勾稽關係 (Interrelationships)
四大報表並非各自獨立，而是存在嚴謹的先後順序與數字傳遞關係（01 P.70, 79, 81；03 P.59）：

- **編表之前置基石**：期末日常分錄與過帳後之試算表（未調整試算表）尚未反映完整權責事實，必須先完成**調整分錄與過帳**，編製出**調整後試算表 (Adjusted Trial Balance)**，才能直接以此作為編製四大報表的正確數據來源（03 P.22, 59）。

$$\text{調整後試算表} \longrightarrow \text{步驟 1: 損益表} \longrightarrow \text{步驟 2: 保留盈餘表} \longrightarrow \text{步驟 3: 資產負債表}$$

- **順序的重要性**：
  1. 必須先編製**損益表**，計算出當期「淨利 (Net Income)」。
  2. 將淨利傳入**保留盈餘表**：$\text{期末保留盈餘} = \text{期初保留盈餘} + \text{當期淨利} - \text{發放股利}$。
  3. 將計算出的「期末保留盈餘」帶入**資產負債表**的權益項目中，資產負債表才能維持平衡（$\text{資產} = \text{負債} + \text{權益}$）。
  4. 最後，現金流量表解釋資產負債表上現金科目從期初到期末的變動成因。

### 3. 一套完整的財務報表 (A Complete Set of Financial Statements)
依據國際財務報導準則（IFRS）觀念架構，一套完整的財務報表（又稱整份財務報表）包含以下構成元件（04 P.72）：
1. **財務狀況表 (Statement of Financial Position)**：我國實務慣稱為「資產負債表 (Balance Sheet)」，報導特定時點之財務狀況。
2. **損益及其他綜合損益表 (Statement of Profit or Loss and Other Comprehensive Income)**：涵蓋當期營運績效之損益表及其他綜合損益。
3. **權益變動表 (Statement of Changes in Equity)**：反映所有者權益各項目之增減變動（包含保留盈餘變動與投入資本）。
4. **現金流量表 (Statement of Cash Flows)**：說明特定期間現金之流入與流出。
5. **附註 (Notes)**：包括重大會計政策之彙總說明與其他必要之解釋性資訊。
6. **前期比較資訊 (Comparative Information)**：提供前一期間之對比數據。
- **等同重要性與交互索引**：所有報表與附註係以「同等重要 (equal prominence)」的地位呈現，且報表項目間均應具備「交互索引 (cross-references)」之功能（04 P.72）。

### 4. 財務報導之觀念架構與資訊品質特性
財務報表的核心目的在於向「主要使用者」（現有與潛在投資人、貸款人及其他債權人）提供「一般目的」之有用決策資訊（04 P.75-76）。

#### (1) 基本品質特性 (Fundamental Qualities)（01 P.76；04 P.77, 84-85）
財務資訊必須同時具備以下兩大基本特性，才具備決策有用性：
- **攸關性 (Relevance)**：資訊足以影響使用者的經濟決策。
  - **預測價值 (Predictive Value)**：協助使用者評估未來可能結果。
  - **確認價值 (Confirmatory Value)**：協助確認或修正過去的評估。
  - **重大性 (Materiality)**：當某項資訊之「遺漏、誤述或模糊」會合理預期影響主要使用者之決策時，該資訊即具重大性（重大性門檻因企業規模與事項性質而異）（04 P.84-85）。
- **忠實表達 (Faithful Representation)**：資訊能真實反映其所欲陳述之經濟現象。
  - **完整性 (Completeness)**：包含理解該現象所需之一切必要描述與解釋。
  - **無偏頗 / 中立性 (Neutrality)**：不蓄意操弄或選擇性呈現資訊以達成特定偏誤結果。
  - **免於重大錯誤 (Free from Error)**：敘述與計算過程沒有重大錯誤或疏漏。

#### (2) 強化品質特性 (Enhancing Qualities)（04 P.78-83）
在滿足基本品質特性的前提下，以下四項特性可進一步提升資訊之有用性（四者之間無必然優先順序）：
- **可比性 (Comparability)**：使使用者能辨識相同企業之跨期趨勢，以及不同企業間之橫斷面對比（重點在於相似經濟活動呈現相似數字，而非機械性統一）（04 P.80）。
- **可驗證性 (Verifiability)**：不同之獨立觀察者能對資訊之忠實表達達成共識（可採直接盤點驗證或間接公式模型驗證）（04 P.81）。
- **時效性 (Timeliness)**：在資訊失去決策影響力之前及時提供給決策者（04 P.82）。
- **可了解性 (Understandability)**：以清楚簡潔方式呈現，供對商業與會計具合理認知之讀者理解（04 P.83）。

#### (3) 全域限制：成本限制 (Cost Constraint)（04 P.86-87）
會計報導在追求高品質資訊時，必須權衡成本與效益——提供財務資訊之效益（包含編製者、使用者與查核者之整體社會效益），必須大於蒐集、驗證與解讀該資訊之成本。

## 手搖飲店例子
- **編表順序**：清爽茶飲店在月底結帳時，張老闆必須先算這個月賣茶飲總共賺了多少淨利（損益表），接著扣除自己領取的 1 萬元分紅、算出店裡留了多少獲利（保留盈餘表），最後才能將店內累積的真實身價列入月底的資產與權益總表（資產負債表）。（教學假設）
- **重大性與成本限制**：清爽茶飲店花了 25 元買了一支原子筆，雖然這支筆可以使用 3 個月（跨越會計期間），但由於金額極小不具重大性，且專門為 25 元按月提列折舊耗費的記帳成本遠大於效益，因此依重大性與成本限制，直接在購買當月作為費用報銷即可。（教學假設）
