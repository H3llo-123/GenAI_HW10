# 會計恆等式 (Accounting Equation)

## 一句話定義
會計恆等式是會計學的核心基石，表達企業所擁有的資源（資產）必定等於這些資源的來源（負債與權益）。

## 詳細說明
會計所有的記錄與討論，均源自會計恆等式：

$$\text{資產 (Assets)} = \text{負債 (Liabilities)} + \text{權益 (Equity)}$$

### 1. 基本架構
- **等號左邊（資產）**：代表企業目前所控制、具未來經濟效益的經濟資源。
- **等號右邊（負債 ＋ 權益）**：代表對這些資產的權利主張或資金來源。負債是「債權人」對資產的索償權；權益是「所有者」扣除負債後的剩餘索償權。

### 2. 不同組織型態下的等式改寫
- **獨資企業 (Proprietorship)**：
  $$\text{資產} = \text{負債} + \text{業主權益}$$
- **合夥企業 (Partnership)**：
  $$\text{資產} = \text{負債} + (\text{合夥人甲權益} + \text{合夥人乙權益})$$
- **公司組織 (Corporation)**：
  公司具有限責任特性，權益通常拆分為原始投入與營運積累：
  $$\text{資產} = \text{負債} + \text{股東權益} = \text{負債} + (\text{股本} + \text{保留盈餘})$$

### 3. 進階會計恆等式 (Expanded Accounting Equation)
由於保留盈餘受營運淨利（收入減費用）與發放股利之影響，會計恆等式可進一步展開為：

$$\text{資產} = \text{負債} + \text{股本} + (\text{收入} - \text{費用} - \text{股利})$$

- 讓權益增加的項目：**股東投資（股本）**、**收入 (Revenues)**。
- 讓權益減少的項目：**費用 (Expenses)**、**發放股利 (Dividends)**。

### 4. 會計恆等式與借貸平衡的數學對應 (02_基本簿記 P.4-5, 20-21)
會計上的「借貸平衡」，在數學本質上正是會計恆等式的「左右相等」：
- **基本等式對應**：
  $$\underbrace{\text{資產 (Assets)}}_{\text{左邊：借方增加 (Dr. +)}} = \underbrace{\text{負債 (Liabilities)} + \text{權益 (Equity)}}_{\text{右邊：貸方增加 (Cr. +)}}$$
- **進階等式對應**：將減項（費用與股利）移至等號左邊，轉換為全正數形式：
  $$\underbrace{\text{資產} + \text{費用} + \text{股利}}_{\text{位於左邊：借記為增加 (Dr. +)}} = \underbrace{\text{負債} + \text{股本} + \text{保留盈餘} + \text{收入}}_{\text{位於右邊：貸記為增加 (Cr. +)}}$$
因此，任何一筆交易只要依照借貸法則登記，「借方總額必定等於貸方總額」，會計恆等式便能永久維持平衡。

### 5. 財務比率：負債比率 (Debt Ratio)
$$\text{負債比率} = \frac{\text{負債}}{\text{資產}}$$
用以衡量企業總資產中有多少比例是由負債（借款）所支應。

## 手搖飲店例子
張老闆開設「清爽茶飲店」，準備了總值 100 萬元的設備、店面押金與現金（資產）。其中 60 萬元是張老闆自己拿出的存款（權益），另外 40 萬元是向銀行申請的青年創業貸款（負債）。
此時會計恆等式為：
$$100\text{ 萬 (資產)} = 40\text{ 萬 (負債)} + 60\text{ 萬 (權益)}$$
等式兩邊完全平衡。（註：金額為教學假設）
