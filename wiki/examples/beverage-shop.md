# 手搖飲店案例 (Beverage Shop Example)

## 一句話定義
手搖飲店案例是貫穿本專案的教學情境，透過「清爽茶飲店」的創立與各項日常交易，具體演示會計恆等式與財務報表的運作。

## 詳細說明
本案例為初學者建立一致性的商業情境。以下示範第一階段：開店與基本日常交易，並展示每筆交易如何使會計恆等式（$\text{資產} = \text{負債} + \text{權益}$）兩端維持平衡。

> **重要說明**：本情境之交易項目與數字係改編自教材中 Softbyte 公司之 10 筆釋例，所有情境與金額皆標註為**「教學假設」**，用以輔助理解概念，非原始教材之歷史事實。

### 案例基本設定
- **店名**：清爽茶飲店
- **業主**：張老闆
- **幣別**：新台幣（元）

### 第一階段：10 筆基本交易分析與恆等式變動

#### 交易 (1)：業主出資成立茶飲店
- **情境**：張老闆拿出個人存款 15,000 元投入「清爽茶飲店」作為創始股本。
- **分析**：
  - 資產端：現金 (Cash) 增加 $+15,000$。
  - 權益端：股本 (Share Capital) 增加 $+15,000$。
- **等式平衡**：$\text{資產 } 15,000 = \text{負債 } 0 + \text{權益 } 15,000$。

#### 交易 (2)：付現購置營業設備
- **情境**：茶飲店以現金 7,000 元購入二手封口機與製冰機。
- **分析**：
  - 資產端：現金減少 $-7,000$，同時設備 (Equipment) 增加 $+7,000$。
  - 負債與權益端：不變。
- **等式平衡**：$\text{資產 } (8,000 + 7,000) = \text{負債 } 0 + \text{權益 } 15,000$。資產內部一增一減，總額維持 15,000。

#### 交易 (3)：賒購外帶包材與耗材
- **情境**：向包材商賒購外帶紙杯、吸管與封口膜共 1,600 元，款項約定下個月清償。
- **分析**：
  - 資產端：用品盤存 / 耗材 (Supplies) 增加 $+1,600$。
  - 負債端：應付帳款 (Accounts Payable) 增加 $+1,600$。
- **等式平衡**：$\text{資產 } 16,600 = \text{負債 } 1,600 + \text{權益 } 15,000$。

#### 交易 (4)：現調茶飲銷售收現
- **情境**：營業首日提供現調茶飲服務，全數收到現金 1,200 元。
- **分析**：
  - 資產端：現金增加 $+1,200$。
  - 權益端：因產生服務收入 (Service Revenue) 使得保留盈餘增加 $+1,200$。
- **等式平衡**：$\text{資產 } 17,800 = \text{負債 } 1,600 + \text{權益 } 16,200$。

#### 交易 (5)：賒購促銷宣傳傳單
- **情境**：委託印刷廠印製開幕促銷傳單 250 元，印刷廠送來帳單，約定次月付款。
- **分析**：
  - 負債端：應付帳款增加 $+250$。
  - 權益端：因發生廣告費用 (Advertising Expense) 使得保留盈餘減少 $-250$。
- **等式平衡**：$\text{資產 } 17,800 = \text{負債 } 1,850 + \text{權益 } 15,950$。

#### 交易 (6)：公司行號團購外送（部分收現、部分賒銷）
- **情境**：接獲附近科技公司大型下午茶外送訂單 3,500 元。科技公司現場支付現金 1,500 元，其餘 2,000 元承諾月底轉帳。
- **分析**：
  - 資產端：現金增加 $+1,500$，應收帳款 (Accounts Receivable) 增加 $+2,000$。
  - 權益端：服務收入增加 $+3,500$（使保留盈餘增加）。
- **等式平衡**：$\text{資產 } 21,300 = \text{負債 } 1,850 + \text{權益 } 19,450$。

#### 交易 (7)：付現支付各項營業費用
- **情境**：茶飲店以現金支付店租 600 元、工讀生薪資 900 元、水電瓦斯費 200 元，共計 1,700 元。
- **分析**：
  - 資產端：現金減少 $-1,700$。
  - 權益端：租金費用 $-600$、薪資費用 $-900$、水電費用 $-200$，使保留盈餘共減少 $-1,700$。
- **等式平衡**：$\text{資產 } 19,600 = \text{負債 } 1,850 + \text{權益 } 17,750$。

#### 交易 (8)：付現清償印刷傳單欠款
- **情境**：茶飲店以現金 250 元付清交易 (5) 欠印刷廠的傳單帳款。
- **分析**：
  - 資產端：現金減少 $-250$。
  - 負債端：應付帳款減少 $-250$。
- **等式平衡**：$\text{資產 } 19,350 = \text{負債 } 1,600 + \text{權益 } 17,750$。

#### 交易 (9)：收回客戶團購賒欠款
- **情境**：收到科技公司轉帳匯入 600 元，用以清償部分應收帳款。
- **分析**：
  - 資產端：現金增加 $+600$，應收帳款減少 $-600$。
  - 負債與權益端：不變。
- **等式平衡**：$\text{資產 } 19,350 = \text{負債 } 1,600 + \text{權益 } 17,750$。資產內部一增一減。

#### 交易 (10)：分派盈餘／發放現金股利
- **情境**：茶飲店獲利良好，決定分派現金 1,300 元給張老闆（發放股利）。
- **分析**：
  - 資產端：現金減少 $-1,300$。
  - 權益端：發放股利 (Dividends) 使保留盈餘減少 $-1,300$。
- **等式平衡**：$\text{資產 } 18,050 = \text{負債 } 1,600 + \text{權益 } 16,450$。

### T 字帳過帳示意：以「現金 (#101)」為例

所有日記簿分錄過入「現金科目 (Cash #101)」T 字帳後之呈現：

```text
                  現金 (Cash, #101)
------------------------------------------------------
借方 (Debit / 增加)        | 貸方 (Credit / 減少)
------------------------------------------------------
(1) 資本投入     15,000   | (2) 購買設備       7,000
(4) 銷售收現      1,200   | (7) 支付費用       1,700
(6) 團購收現      1,500   | (8) 償還欠款         250
(9) 收回應收款      600   | (10) 發放股利      1,300
------------------------------------------------------
借方合計         18,300   | 貸方合計          10,250
------------------------------------------------------
正常餘額 (借餘)   8,050   |
```

*驗證*：借方 18,300 － 貸方 10,250 ＝ **借餘 8,050 元**，與第一階段恆等式期末現金完全吻合。

### 第三階段：延伸至買賣業（保溫杯轉售業務）

依照 AGENTS.md 第 7.1 節規範，本階段引進買賣業交易，具體呈現「購買商品」、「販售商品」以及「買賣業與一般服務業之差異」：

#### 業務背景
清爽茶飲店營運步上軌道後，張老闆決定在門市櫃檯設立周邊商品展示架，跨足買賣業，向配合廠商批量進貨印有店徽的「不銹鋼保溫杯」進行轉售。

#### 交易 (11)：批發購入商品存貨（購買商品）
- **情境**：張老闆以批發價每個 150 元，向製造廠購入 100 個保溫杯，共支付現金 15,000 元（FOB 目的地交貨，商品送達門市驗收合格入庫）。
- **日記簿分錄**：
  ```text
  借：商品存貨 (Merchandise Inventory)    15,000
      貸：現金 (Cash)                               15,000
  ```
- **恆等式分析**：
  - 資產端：現金減少 $-15,000$，商品存貨增加 $+15,000$。
  - 負債與權益端：不變。
  - 等式維持平衡：資產內部項目交換，總資產金額不變。清爽茶飲店正式擁有一筆「商品存貨」資產。

#### 交易 (12)：門市零售保溫杯（販售商品）
- **情境**：某科技公司福委會向茶飲店訂飲料時，看中展示的保溫杯，當場以現金買走 60 個保溫杯作為員工抽獎禮品。門市零售價為每個 250 元，茶飲店全數收取現金 15,000 元。
- **日記簿分錄（買賣業之雙重認列）**：
  買賣業賣出商品時，必須同時記錄「收入的產生」與「存貨轉列為銷貨成本」兩件事（05 P.38）：
  ```text
  1. 認列銷貨收入（按零售價）：
  借：現金 (Cash)                              15,000
      貸：銷貨收入 (Sales Revenue)                  15,000

  2. 結轉銷貨成本（按成本價 60 個 × 150 元 = 9,000 元）：
  借：銷貨成本 (Cost of Goods Sold)             9,000
      貸：商品存貨 (Merchandise Inventory)           9,000
  ```
- **恆等式分析**：
  - 資產端：現金增加 $+15,000$，商品存貨減少 $-9,000$，資產淨增加 $+6,000$。
  - 權益端：銷貨收入使權益增加 $+15,000$，銷貨成本使權益減少 $-9,000$，權益淨增加 $+6,000$。
  - 等式維持平衡：$\text{資產淨增 } +6,000 = \text{負債 } 0 + \text{權益淨增 } +6,000$！

#### 買賣業成果與服務業差異解析
1. **庫存狀況**：
   - 保溫杯進貨 100 個，售出 60 個，剩餘 40 個。
   - 期末資產負債表上將列有「商品存貨 6,000 元」（$40 \times 150$），隨時待售。
2. **多步驟損益衡量**：
   - 銷貨收入：15,000 元
   - 銷貨成本：9,000 元
   - **銷貨毛利 (Gross Profit)**：$15,000 - 9,000 = \mathbf{6,000\text{ 元}}$。
   - **銷售毛利率**：$6,000 / 15,000 = \mathbf{40\%}$。
3. **差異體會**：
   - 服務業（如現泡茶飲）主要靠勞務創造收入，紙杯與茶葉屬於耗材，無商品存貨；
   - 買賣業（如賣保溫杯）則以賺取進銷差價為核心，每次賣出商品皆需同步扣減存貨並認列銷貨成本，在報表上多出「銷貨毛利」指標。
